# 잎 효과 후보 — 보관

만들기 화면(/character)의 잎 효과를 정할 때 만들어 본 후보 페이지. 브라우저로 그대로 열면 된다(서버 없이 파일만 열어도 동작함).

- `candidates-abc.html` — 잎 효과 세 가지(A 물들기 / B 돋아나기 / C 돋아 짙어지기) 비교. C를 골라 실제 화면에 반영했다.
- `color-compare.html` — 잎 색 비교(자주 / 초록), 밝은 화면·어두운 화면 네 가지를 한 화면에서 비교. 자주를 골라 실제 화면에 반영했다.

실제 화면의 구현은 `src/character_page.py`의 `.cm-twig` 관련 CSS·JS에 있다. 이 폴더의 파일들은 거기 반영하기 전 미리 보던 자리라서, 실제 화면과 색·수치가 맞지 않을 수 있다.
